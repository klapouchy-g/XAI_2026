## Overview
This project builds a Speech Emotion Recognition system that takes short voice clips and predicts the speaker’s emotion using audio features. It also applies Explainable AI methods, such as SHAP/LIME and Grad-CAM, to show which parts of the audio or frequency patterns influenced the model’s prediction.

## Dataset
https://www.kaggle.com/datasets/uwrfkaggler/ravdess-emotional-speech-audio
